# Задачи

Решение каждой задачи пиши в файл `solutions/task_XX.sql`, затем запускай `pytest`.
Тест сравнивает результат твоего запроса с эталоном: важны **столбцы, их порядок и порядок строк**.

Схема базы — в `db/schema.sql`, данные — в `db/seed.sql`.
Попробовать любой запрос можно командой `python sql.py "SELECT * FROM customers"`.

---

## Основы: SELECT, WHERE, ORDER BY, GROUP BY

**01.** Имена всех покупателей из Астаны.
Столбцы: `name`. Сортировка: по имени.

**02.** Товары дороже 50 000 тенге.
Столбцы: `name`, `price`. Сортировка: от самого дорогого.

**03.** Сколько заказов в каждом статусе.
Столбцы: `status`, количество. Сортировка: по статусу.

**04.** Покупатели, зарегистрированные в 2026 году.
Столбцы: `name`, `registered_at`. Сортировка: по дате регистрации.

## Связи между таблицами: JOIN

**05.** Заказы с именами покупателей. Заказы, у которых покупатель не найден, не показывать.
Столбцы: id заказа, имя покупателя, `status`. Сортировка: по id заказа.

**06.** Сумма каждого заказа (цена × количество по всем товарам заказа). Заказы без товаров не показывать.
Столбцы: `order_id`, сумма. Сортировка: по `order_id`.

**07.** Топ-3 покупателя по сумме **доставленных** (`delivered`) заказов.
Столбцы: имя, сумма. Сортировка: от большей суммы.

**08.** Выручка по категориям товаров — только оплаченные и доставленные заказы (`paid`, `delivered`).
Столбцы: `category`, выручка. Сортировка: от большей выручки.

**09.** Покупатели, у которых нет ни одного заказа.
Столбцы: `name`. Сортировка: по имени.

**10.** Количество заказов по городам покупателей, без отменённых (`cancelled`).
Столбцы: `city`, количество. Сортировка: по количеству от большего, при равенстве — по городу.

## Проверка данных: задачи тестировщика

В данных намеренно есть ошибки. Найди их запросами — именно так тестировщик проверяет, что в базе всё корректно.

**11.** Email, которые встречаются у нескольких покупателей (дубли).
Столбцы: `email`, количество.

**12.** Заказы, которые ссылаются на несуществующего покупателя.
Столбцы: id заказа. Сортировка: по id.

**13.** Заказы, в которых нет ни одного товара.
Столбцы: id заказа. Сортировка: по id.

**14.** Товары с некорректной ценой — ноль или меньше.
Столбцы: `name`, `price`. Сортировка: по названию.

## Подзапросы

**15.** Товары дороже средней цены по всем товарам.
Столбцы: `name`, `price`. Сортировка: от самого дорогого.
